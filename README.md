# 🚇 Skip-ADS-Metro-SPB

Userscript для автоматического прохождения рекламных экранов при подключении к
Wi-Fi в метро Санкт-Петербурга.

[![Version](https://img.shields.io/badge/version-2.0.0-2563eb.svg)](./metrospb.js)
[![License](https://img.shields.io/badge/license-MIT-059669.svg)](./LICENSE)

Скрипт находит кнопки подключения и пропуска рекламы, ускоряет клиентские
таймеры и рекламные видео. Работает только на доменах портала Wi-Fi:
`wi-fi.ru`, `vmet.ro` и `gowifi.ru`.

## Что умеет

- Нажимает только видимые и активные кнопки.
- Поддерживает русские и английские названия действий.
- Ускоряет длинные таймеры в 20 раз, не трогая короткие задержки интерфейса.
- Ставит рекламным видео скорость до `16x` и выключает звук.
- Реагирует на изменения страницы через `MutationObserver`.
- Не нажимает одну кнопку чаще раза в 3 секунды.
- Выполняет только одно действие за проход, чтобы не перескочить через
  незагруженный экран.
- Игнорирует платную кнопку отключения рекламы.

### Распознаваемые действия

| Русский | English |
|---|---|
| Обычная поездка | Regular trip |
| Стандартная поездка | Standard trip |
| Подключиться | Connect |
| Войти в интернет | Go online / Enter internet |
| Далее | Next |
| Продолжить | Continue |
| Пропустить рекламу | Skip ad / Skip advertisement |
| Закрыть | Close / Dismiss |

Поддерживаются и варианты с обратным отсчётом, например `Next in 5` или
`Пропустить через 5`.

## Установка

### Windows, macOS и Linux

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Создайте новый userscript.
3. Замените его содержимое кодом из [metrospb.js](./metrospb.js).
4. Сохраните скрипт и убедитесь, что он включён.

### iPhone и iPad

1. Установите [Userscripts](https://apps.apple.com/app/userscripts/id1463298887).
2. Откройте `Настройки → Safari → Расширения → Userscripts` и включите
   расширение.
3. Разрешите расширению работать на сайтах.
4. В приложении Userscripts выберите папку через
   `Set Userscripts Directory`.
5. Сохраните в эту папку файл [metrospb.js](./metrospb.js).

Если captive portal открылся во встроенном окне iOS и расширение не запустилось,
откройте страницу авторизации в Safari.

### Android

Обычный Chrome для Android не запускает userscript-расширения. Используйте
браузер с поддержкой расширений и установите совместимый менеджер userscript.
После этого добавьте в него [metrospb.js](./metrospb.js).

## Использование

1. Подключитесь к сети `MT_FREE`.
2. Откройте появившуюся страницу авторизации.
3. Оставьте вкладку открытой: дальнейшие подходящие кнопки скрипт нажмёт сам.

Для проверки работы откройте консоль браузера. Сообщения скрипта начинаются с:

```text
[Skip-ADS 2.0.0]
```

## Как это устроено

Скрипт запускается в начале загрузки страницы и сохраняет нативные браузерные
таймеры для собственных задач. Таймеры портала длительностью от 1 до 60 секунд
ускоряются контролируемо. Появление новых кнопок и изменение их состояния
отслеживается без постоянного полного перебора DOM.

Перед нажатием проверяются:

- точное название действия;
- видимость элемента;
- размеры элемента;
- атрибуты `disabled` и `aria-disabled`;
- время с предыдущего нажатия.

## Проверка и разработка

Понадобится Node.js 18 или новее.

```bash
npm ci
npm test
```

Тест проверяет русские и английские кнопки, динамическое появление элементов,
игнорирование платных и неподходящих действий, защиту от нажатия
`disabled`-кнопок и сохранение аргументов ускоренного `setTimeout`.

## Ограничения

- Если длительность рекламы проверяется сервером, клиентский скрипт не сможет
  мгновенно завершить ожидание.
- Captive portal и названия кнопок могут измениться после обновления провайдера.
- Встроенное окно авторизации операционной системы может не поддерживать
  userscript-расширения.
- Полный сценарий до получения интернета можно проверить только при подключении
  к реальной сети метро.

На живом `auth.wi-fi.ru` подтверждены кнопки `Connect`, `Next`,
`Continue`, рекламные iframe и video-элементы. Платное действие
`Turn-off advertising for 1 rub` намеренно не входит в список автокликов.

## Если не работает

1. Убедитесь, что userscript включён для текущего сайта.
2. Откройте авторизацию в обычной вкладке браузера.
3. Проверьте консоль на наличие строки `[Skip-ADS 2.0.0] Запущен`.
4. Создайте issue и приложите адрес страницы, текст кнопки и сообщения консоли.
