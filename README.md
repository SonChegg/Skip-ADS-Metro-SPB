# 🚇 Skip-ADS-Metro-SPB

**Автоматический пропуск рекламы и ускорение авторизации в Wi-Fi сети метрополитена (СПБ).**

![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Этот скрипт автоматически нажимает кнопки "Войти в интернет", "Пропустить рекламу", ускоряет таймеры ожидания и рекламные видеоролики, позволяя подключиться к сети за несколько секунд.

## 🚀 Возможности

*   **⚡ Контролируемое ускорение:** Ускоряет длинные таймеры (`setTimeout`/`setInterval`) в 20 раз, не трогая короткие интерфейсные задержки.
*   **⏩ Скип видео:** Автоматически ускоряет рекламные видеоролики (playbackRate x16) и выключает звук.
*   **🤖 Авто-клик:** Находит видимые кнопки "Пропустить", "Закрыть", "Войти" и нажимает каждую не чаще одного раза в 3 секунды.
*   **🪶 Низкая нагрузка:** Реагирует на изменения страницы через `MutationObserver` вместо полного обхода DOM каждые несколько миллисекунд.
*   **🛡️ Безопасный режим:** Скрипт активируется **только** на доменах Wi-Fi провайдера (`wi-fi.ru`, `vmet.ro` и др.), не ломая работу обычных сайтов (YouTube, VK, Google).
*   **📱 Mobile Friendly:** Эмулирует Touch-события для лучшей работы на мобильных устройствах.

## 📦 Установка

### 🖥️ Для ПК (Desktop)
1. Установите расширение для управления скриптами:
   *   [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется)
   *   Violentmonkey
2. Создайте новый скрипт и скопируйте в него содержимое файла `metrospb.js`.
3. Сохраните (Ctrl+S).

---

### 🍎 Для iOS (iPhone / iPad)
Используем бесплатное расширение **Userscripts** для Safari.

1. Установите приложение **[Userscripts](https://apps.apple.com/us/app/userscripts/id1463298887)** из App Store.
2. Включите его в настройках Safari:
   *   `Настройки` -> `Safari` -> `Расширения` -> `Userscripts` -> **Включить**.
   *   Там же убедитесь, что в разделе "Разрешения для веб-сайтов" выбрано **"Разрешить"** или **"Все веб-сайты"**.
3. Настройте папку:
   *   Откройте приложение **Userscripts**.
   *   Нажмите **Set Userscripts Directory** и выберите любую папку в "Файлах" (iCloud или На iPhone), где будут лежать ваши скрипты.
4. Установите скрипт:
   *   Сохраните файл скрипта как `metrospb.js` в выбранную вами папку.
   *   Откройте Safari, нажмите на значок `аА` (или пазл) в адресной строке -> Userscripts. Вы должны увидеть, что скрипт активен.

---

### 🤖 Для Android
Chrome на Android не поддерживает расширения. Используйте браузеры с поддержкой дополнений.

**Вариант А: Firefox / Iceraven (Рекомендуется)**
1. Установите **Firefox** для Android.
2. Зайдите в меню (три точки) -> **Дополнения**.
3. Найдите и установите совместимый менеджер userscript-скриптов.
4. Откройте его настройки и создайте новый скрипт, скопировав код из `metrospb.js`.

**Вариант Б: Kiwi Browser**
1. Установите **Kiwi Browser**.
2. Установите **Tampermonkey** из обычного Chrome Web Store (как на ПК).
3. Добавьте скрипт через панель управления Tampermonkey.

## ⚙️ Как это работает

При подключении к Wi-Fi в метро (`MT_FREE`):
1. Браузер открывает страницу авторизации.
2. Скрипт обнаруживает "Captive Portal".
3. Аккуратно ускоряет длинные таймеры и рекламный видеоплеер.
4. Следит за появлением новых элементов и нажимает подходящие кнопки без постоянного опроса страницы.

> Скрипт ускоряет клиентскую часть портала. Если ожидание проверяется сервером,
> полностью убрать его невозможно.
